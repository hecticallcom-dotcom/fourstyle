3. The website works offline (except product images from Unsplash)

- Top scrolling announcement bar
- Sticky header with logo
- Navigation with dropdowns
- Mobile responsive hamburger menu
- Hero section
- Category cards
- Product grid with sale badges
- Add to Cart functionality (saved in browser)
- Cart sidebar
- Testimonials
- FAQ accordion
- Why Choose Us section
- Newsletter form
- Footer
- Floating WhatsApp button
- Fully responsive (mobile + desktop)

LOGO:

and used in Header + Footer.
